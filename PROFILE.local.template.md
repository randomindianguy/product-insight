# PROFILE.local.template.md

Copy this to `PROFILE.local.md` (gitignored — never commit) and fill it privately.
`/thesis` Step 6 reads it if present and works without it if absent.

**One rule governs every line: write warnings to check, never facts about yourself.**
A fact hardens into a rut the skill steers you into. A warning is a mirror it holds
up. The difference is the whole value of the file.

- Fact (wrong): *"I build eval harnesses."*
  → The skill steers every thesis toward an eval harness. The tic becomes a cage.
- Warning (right): *"Watch whether this artifact is eval-shaped because it fits my
  existing work rather than because the company needs one."*
  → The skill checks the tic instead of feeding it.

Every entry below is phrased as *watch-for*. Keep it that way. Delete these
instructions once you've filled your own in.

---

## Failure patterns — watch-for, not is

- [Watch for (a tendency), especially when (the condition that triggers it).]
- [Watch for (a reach you make) when (the situation where it misleads).]
- [Be honest and specific. Vague warnings don't fire.]

---

## Past burns — the wall, pointed at yourself

The transfer test is strongest when it's concrete. A time an imported instinct led you
wrong is worth more than any abstract caution, because it names a real condition that
broke. One line each: the instinct, the condition you assumed, what was actually true.

- [*"I assumed (instinct) because (condition I believed held). Actually (what was
  true), and it cost (what) — so when I reach for (instinct) again, check (condition)
  first."*]

These are walls in your own sense — an obstacle only you hit, that nobody borrows. If
you have even one real burn, it's the most valuable line in either profile file.
